# 利用規約

この利用規約（以下，「本規約」といいます。）は，毎日雑学（以下，「当方」といいます。）が提供するアプリケーション「毎日雑学」（以下，「本アプリ」といいます。）の利用条件を定めるものです。登録ユーザーの皆さま（以下，「ユーザー」といいます。）には，本規約に従って，本アプリをご利用いただきます。

## 第1条（適用）
本規約は，ユーザーと当方との間の本アプリの利用に関わる一切の関係に適用されるものとします。

## 第2条（利用登録）
本アプリの利用希望者が当方の定める方法によって利用登録を申請し，当方がこれを承認することによって，利用登録が完了するものとします。

## 第3条（有料プラン・サブスクリプションについて）
1. **プラン内容**
   本アプリでは、より便利な機能を利用できる有料プラン（サブスクリプション）を提供しています。
   - 広告の非表示
   - 過去の雑学の無制限閲覧
   - その他、アプリ内で提示する機能

2. **課金**
   有料プランの料金は、Apple ID（iTunesアカウント）に請求されます。

3. **自動更新**
   有料プランは自動更新型のサブスクリプションです。有効期間終了の24時間前までに自動更新を解除しない限り、登録期間が自動的に更新されます。
   更新分の料金は、有効期間終了の24時間前から終了までの間に請求されます。

4. **解約方法**
   ユーザーは、ご自身のApple IDの設定から、いつでもサブスクリプションの自動更新を解除（解約）することができます。
   アプリの削除やログアウトだけでは解約されませんのでご注意ください。
   [設定] > [Apple ID] > [サブスクリプション] から変更・解除が可能です。

5. **利用料金の変更**
   当方は、必要と判断した場合、有料プランの利用料金を変更することができるものとします。

1. 法令または公序良俗に違反する行為
2. 犯罪行為に関連する行為
3. 本アプリのサーバーまたはネットワークの機能を破壊したり，妨害したりする行為
4. 当方のサービスの運営を妨害するおそれのある行為
5. 他のユーザーに関する個人情報等を収集または蓄積する行為
6. 不正アクセスをし，またはこれを試みる行為
7. その他，当方が不適切と判断する行為

1. 本アプリにかかるコンピュータシステムの保守点検または更新を行う場合
2. 地震，落雷，火災，停電または天災などの不可抗力により，本アプリの提供が困難となった場合
3. コンピュータまたは通信回線等が事故により停止した場合
4. その他，当方が本アプリの提供が困難と判断した場合
